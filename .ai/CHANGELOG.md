## 2026-10-09 - Supplier permit list (branch `claude/supplier-permit-list`)

Added the supplier permit list to Analytics. Pipeline: `scripts/supplier-permits/parse-construction-monitor.py` reads the weekly PDF's three-column layout by font, colour and indent and refuses to write unless the residential and commercial permit counts equal the report's own week totals (week 40: 598 approved permits, matched). `scripts/build-supplier-permits.mjs` (thin) calls `scripts/supplier-permits/pipeline.mjs`, which uses `fetch.mjs` (county case numbers validated against a strict pattern and sent in chunks of 40; street prefix search with quotes doubled and wildcards removed; active L&I licenses with type and specialty) and `lib.mjs` (pure: validation, address standard form, parcel choice, builder / license / list matching, signals, merge SQL). Shared rules, columns, DDL and readers live in `functions/internal/_lib/supplier-permits.mjs`, used by the loader, the endpoint, the page and the tests. `scripts/permit-leads/fetch.mjs` gained optional field lists (defaults unchanged, tested) and exports its paging helpers.

Decisions: a parcel is chosen only when exactly one parcel at the street matches in standard form (unit ignored); several parcels, or only a longer street name, are left blank rather than guessed. A name cut off by the report matches a tracked builder only when it looks truncated (25+ characters or ending in Of / And / The) and starts the tracked name; "HSR 124 LLC" next to a tracked "HSR 121 LLC" is a "check" hint, never a match. A one-word ranking row never claims a longer builder name. A new home with no contractor listed uses its owner company as the builder. The fit score drops "owner applied" (the report names roles, not applicants) for "no contractor named"; it is shown for remodel, ADU and re-roof permits only. A $0 transfer is not a sale. The merge SQL refuses to let an older file overwrite a newer row or the newer edition label.

Week 40 result: 197 Clark County permits enriched; 50 found as county permit records (property id), 128 more matched by exact street, 15 no match, 4 ambiguous; 26 already in permit leads (21 same permit, 5 same street), 4 in the mail pilot; 41 builders matched to an active L&I license by business name; 30 of 48 new-home permits are by builders already tracked. All permits in this edition are approved (none pending). `recent_permit` is true for every scored permit in this edition (permit dates run Aug 17 to Sep 25), so it will only separate rows once several weeks are loaded.

Validation: `npm run test:supplier-permits` (new CI step) and `npm run test:all`. Not tested here: the production load and the live page (pending merge and deploy), a real phone, and the PDF parser on a second week's report.
